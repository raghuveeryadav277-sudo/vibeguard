# Scanner Tools

App do free, open-source scanner tools use karta hai. Inki badi binary files
(~155 MB) GitHub repo me nahi rakhi gayi hain — official releases se download
karke neeche wale folders me rakho, app khud utha lega:

| Tool | Download | Folder |
|---|---|---|
| Gitleaks v8.30.1 | https://github.com/gitleaks/gitleaks/releases | `tools/gitleaks-windows/` (Windows) ya `tools/gitleaks-linux/` |
| OSV-Scanner v2.7.0 | https://github.com/google/osv-scanner/releases | `tools/osv-windows/` (Windows) ya `tools/osv-linux/` |

Note: bina in tools ke bhi app ke built-in security rules kaam karte hain —
demo app ka scan aur score (34 → 87 → 100) bina inke bhi chalta hai.
